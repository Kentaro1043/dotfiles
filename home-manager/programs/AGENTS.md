# エージェント向け規約

## Git Commit

Commit指示は、以下の3通りからいずれかを行います。

- Commit,Pushしない
- Commitのみを行い、Pushはしない(デフォルト)
- yeetスキルを用いてPRを作成する

Git Commitを行う場合は、Conventional Commits規約とGitmojiを使用し、コミットメッセージは日本語で書いてください。
例を以下に示します。

> feat: ✨ 新規機能を実装

作業の規模が大きいときは、適切な機能単位でCommitを行ってください。

## コードコメント

長すぎるコメントは避けてください。

複数行に渡って日本語の文章を書くのではなく、基本的には1~2行の説明を書く程度にしてください。

ただし重要情報や、必要なコマンド、生成などに使用したコマンドのログがある場合はその限りでありません。

動作元PCに依存したコメントは、コード共有前に削除する必要が生じるため書かないでください。

## フォーマッタ・リンタ

各言語について業界標準のフォーマッタ・リンタを使用し、コード品質を保ってください。
